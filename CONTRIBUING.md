# Contribuindo para o Awesome CLI

Obrigado por ajudar a tornar o terminal um lugar melhor! Para manter a lista organizada, siga estas diretrizes:

### Diretrizes de Envio
1.  **Formato**: Use o padrão `* [Nome](link) - Descrição curta.`
2.  **Ordem**: Tente manter os itens em ordem alfabética dentro das categorias.
3.  **Qualidade**: Certifique-se de que o repositório da ferramenta é funcional e útil.
4.  **Markdown**: Verifique se os links estão funcionando e se o Markdown não possui erros.

### Como enviar
1. Faça um Fork deste repositório.
2. Crie uma branch para sua ferramenta (`git checkout -b add-minha-ferramenta`).
3. Adicione a ferramenta na categoria correta.
4. Faça o commit (`git commit -m 'Add: Nome da Ferramenta'`).
5. Abra um Pull Request.
